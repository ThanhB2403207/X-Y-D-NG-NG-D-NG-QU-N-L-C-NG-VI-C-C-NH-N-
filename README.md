# ĐỀ TÀI 29 - QUẢN LÝ CÔNG VIỆC CÁ NHÂN

## Cấu trúc
- `main.py`: chương trình chính, menu và điều hướng.
- `cau_hinh.py`: hằng số và cấu hình dùng chung.
- `kiem_tra.py`: kiểm tra và nhập dữ liệu.
- `hien_thi.py`: hiển thị danh sách và chi tiết.
- `quan_ly_cong_viec.py`: thêm, cập nhật, xóa công việc.
- `tim_kiem.py`: tìm kiếm.
- `sap_xep.py`: sắp xếp.
- `thong_ke.py`: tính toán/thống kê.
- `file_manager.py`: đọc/ghi file TXT.
- `congviec.txt`: dữ liệu mẫu.
- `quan_ly_cong_viec_goc.py`: bản gốc để đối chiếu.

## Chạy
Mở Terminal tại thư mục và chạy:
`python main.py`
